## 🚀 我的作品

### 📱 Xing-control · 虚拟按键方案
[![项目类型](https://img.shields.io/badge/类型-虚拟按键配置-lightgrey?style=flat-square)](https://github.com/xigiy/Xing-control)
[![工具](https://img.shields.io/badge/制作工具-FoldCraft_可视化编辑器-orange?style=flat-square)](https://github.com/xigiy/Xing-control)

**不用写代码，也能让手机玩Java版MC更顺手！**

这是我早期用 **FoldCraft Launcher 自带的可视化编辑器**，像搭积木一样拖拽出来的虚拟按键方案，全部配置都放在 [`Xing-control`](https://github.com/xigiy/Xing-control) 仓库里。就像在手机屏幕上画了一套“键盘”，点一下按钮就能实现游戏里的各种操作。

*   **解决了什么问题**：手机触屏玩《我的世界》Java版，点不准、操作慢？这套方案让手机操作更接近电脑手感。
*   **我怎么做的**：完全不用写代码，全靠编辑器的**拖拽、摆放、设置参数**，像设计UI界面一样完成了整套按键布局。
*   **适合谁用**：想在手机上玩Java版MC，又觉得默认操作不方便的玩家。

### 🤖 Mot-Ai-Bot · 能自动聊天的AI助手
[![项目状态](https://img.shields.io/badge/状态-进行中-brightgreen?style=flat-square)](https://github.com/xigiy/Mot-Ai-Bot)
[![类型](https://img.shields.io/badge/类型-自动化机器人-blue?style=flat-square)](https://github.com/xigiy/Mot-Ai-Bot)

**就是这个!发动态时说的那个“聊天AI”**

它能自己“蹲”在网页聊天室里，看到有人叫它名字，就自动跳出来回复。整个过程像设置了一套“如果…就…”的自动化规则。

*   **它能做什么**：
  *   👂 **自动监听**：实时看着聊天室里谁说了什么
  *   🏷️ **识别名字**：当有人提到“机器人”或它的名字，它就“醒”过来
  *   💬 **自动回复**：根据对方说的话，自动生成一句合适的回应发出去
*   **我怎么实现的**：通过图形化工具，像搭建流程图一样，把“收到消息→判断是不是叫我→生成回答→发送出去”这些步骤连接起来，它就活过来了。
